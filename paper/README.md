# Submitted Paper

`trajectory_dependence.tex` is the canonical TeX source corresponding to the
submitted compiled manuscript `trajectory-dependence.pdf`. The three PNG files
are the figure assets referenced by the source.

With a TeX distribution that provides `IEEEtran`, compile from this directory:

```bash
latexmk -pdf trajectory_dependence.tex
```

The manuscript is included as a submitted work, not as a claim of conference
acceptance or formal publication.
